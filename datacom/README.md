# WCD Bank Cloud Migration Simulation

## Project Purpose
This project simulates the implementation phase of a strategic IT infrastructure migration for **WCD Bank**, transitioning from on-premises data centers to cloud-based services. This simulation covers cloud application registration and the establishment of CI/CD pipelines.

## Key Tasks
- **Cloud Registration:** Configuration of service principals and IAM roles.
- **Workflow Automation:** Implementation of GitHub Actions for automated deployment testing.

## Technical Stack
- **Version Control:** Git/GitHub
- **DevOps:** GitHub Actions (YAML)
- **Concepts:** CI/CD Pipelines, Environment Variables, IAM Security

## How to use this Repo
1. Clone the repository: `git clone https://github.com/[YOUR-USERNAME]/wcd-bank-cloud-migration.git`
2. View the workflow logic in `.github/workflows/main.yml`.
